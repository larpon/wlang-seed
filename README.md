# wlang-seed

This repository contains the C seed source code for bootstrapping the W compiler (`wlang`).

Each seed file is a C (C99) source of a self-hosted W compiler (`cmd/wlang.w` in the W repository)
generated by a stage 2 ("`w2`") compiler.

Currently there's a seed file for each OS and architecture:

| File | Target |
|---|---|
| `wlang_linux_amd64.c` | Linux, x86-64 |

## Bootstrapping

`wlang`'s own `Makefile` should already do this:

Clone this repository to `seed/` in `wlang` project root and run:

```bash
make
```

Compiling from a seed currently needs a C compiler and `libffi`:

```bash
cc -std=gnu11 -w wlang_linux_amd64.c -o w0 -lffi -ldl
```

## Refreshing a seed

In the `wlang` project root, with a working `cmd/wlang` run:

```bash
make seed
```
